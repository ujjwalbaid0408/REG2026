     OpenSlide CANNOT open. The old container read those as all-zero features
     (wrong predictions on the most important organ) and would OOM-crash on the
     largest ones. src/common/wsi.py now falls back to a BOUNDED, band-major
     strip decoder (one strip at a time, ~0.4–0.6 GB peak regardless of slide
     size — verified on an 8,556-megapixel slide and on all 350 test slides).
     Requires tifffile + imagecodecs, both already in requirements.txt.

     The UNI2-h arch (vit_giant_patch14_reg4_dinov2 + SwiGLUPacked + reg_tokens)
     needs a recent timm; an older resolve would make the UNI2-h load throw and
     the model would SILENTLY fall back to the ~0.25 baseline. This is the same
     failure class as the REV-2 missing-transformers bug. 1.0.27 is the version
     validated end-to-end (0 errors / 0 bad schema across all 350 test slides).

WHAT THIS IS
------------
A self-contained REG2026 algorithm submission for reg2026.grand-challenge.org.
The container is CODE-ONLY; the trained weights ship SEPARATELY as model.tar.gz
(built locally by do_save.sh, see STEP 2). The bundle already has model/ fully
staged (CONCH + UNI2-h encoders + fusion MIL head + label maps + templates), so

access. Everything needed is inside the tarball.

Target inference environment (Grand Challenge): single A10G GPU (sm_86),
<= 32 GB RAM, < 5 min/case, fully OFFLINE.

If it is missing, the most likely causes are an old `timm`, missing
`transformers`, or missing `imagecodecs` — all are pinned in requirements.txt,
so a clean rebuild (`docker build --no-cache`) usually fixes it.

------------------------------------------------------------------------------
STEP 2 — BUILD THE IMAGE + PACK THE MODEL
------------------------------------------------------------------------------
You do NOT need to run prepare_model.sh — model/ is already fully staged in the
bundle (that script only runs on the training cluster). Just run:

    ./do_save.sh

This does three things:
  1. Builds the Docker image  (tag: reg2026_algorithm).
  2. Saves it to              reg2026_algorithm_<timestamp>.tar.gz   (the IMAGE).
  3. Packs model/ contents to model.tar.gz                          (the MODEL).
     model.tar.gz is the contents of model/ at the archive root (./conch/,
     ./uni2h/, ./mil_head.pt, ./label_maps.json, ./templates_full.json) — this
     is ~3 GB because it contains both encoders.
